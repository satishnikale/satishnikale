## Featured Projects

### Excalidraw — Real-Time Collaborative Whiteboard

> *Multi-user drawing that actually feels instant.*

Built a collaborative whiteboard from scratch using **Next.js + WebSockets**, achieving sub-200ms latency for live drawing across multiple users. The backend uses **PostgreSQL + Prisma** to persist canvas history and session states — so your work is never lost when you refresh.

**Stack:** `Next.js` `WebSockets` `PostgreSQL` `Prisma` `JWT` `Turborepo`

**What makes it real:**
- Real-time sync with <200ms latency for a seamless collaborative feel
- JWT-based auth to protect sessions and user workspaces
- Canvas state + session history persisted to PostgreSQL via Prisma
- Turborepo monorepo setup reduced build times by ~40%

---

### StudyNotion — Full-Stack Ed-Tech Platform

> *Not just a course listing — a complete learning ecosystem.*

Designed and built a production-grade Ed-Tech platform where instructors can publish courses and students can enroll, track progress, and pay securely. Built with a clean separation of concerns between the frontend (React.js) and a RESTful Express.js API.

**Stack:** `React.js` `Node.js` `Express.js` `MongoDB` `Razorpay` `Cloudinary`

**What makes it real:**
- Full course lifecycle — creation, enrollment, progress tracking via REST APIs
- Razorpay payment gateway integration for secure transactions
- Cloudinary for scalable media hosting (thumbnails, course content)
- Role-based access control for students vs instructors

---

### EzyEV — Production Fintech Integrations *(Internship)*

> *Real users. Real money. Real-world constraints.*

As part of my internship, I've shipped multiple production features including a **Razorpay payment + webhook pipeline** for real-time order verification, a **KYC onboarding flow** using Cashfree + Aadhaar OTP, and a **WhatsApp chatbot** that handles automated rider and partner queries — reducing manual support load significantly.

**Stack:** `Next.js` `Node.js` `REST APIs` `Razorpay` `Cashfree` `WhatsApp API`

**What makes it real:**
- Payment flows handling real transactions with webhook verification
- Biometric KYC pipeline for rider onboarding at scale
- Chatbot integration that automated high-volume support queries
- Bug fixes and UX improvements on production dashboards used daily
